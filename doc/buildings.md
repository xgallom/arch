# List of buildings

## [G]old Mine

```
MM
```

Build price: 50g

Gathers gold. Can be built on gold veins. Starts with one miner.

### [Z] Add miner

Price: 50g

Adds +1 to amount gathered / gather period. Max 5 miners per mine

## [L]umber Mill

```
LL
```

Build price: 200g

Gathers lumber. Can be built next to trees. Starts with one woodcutter.

### [Z] Add woodcutter

Price: 50g

Adds +1 to amount gathered / gather period. Max 5 woodcutters per lumber mill.

## [B]arracks

```
BB
```

Produces defenders, archers, knights.


## [C]ollege

CC
